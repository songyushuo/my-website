## 本地打开

直接双击 `index.html` 用浏览器打开即可。

也可以起一个本地服务器（体验和线上一致）：

```bash
# 任选其一
python -m http.server 8000
# 或
npx serve .
```

然后访问 <http://localhost:8000>。
